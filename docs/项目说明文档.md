## 二、作品信息

| 项目 | 内容 |
| --- | --- |
| 作品名称 | 天台夜班（Rooftop Night Shift） |
| 作品简介 | 一款纯前端网页叙事解谜游戏：玩家是深夜天台便利店的值守者，在营业区完成扫码、冲咖啡、交单，从票签上破解出三位密码进入仓库，装配传送门后把这一夜交给下一棒世界。核心创意是"接力式存档"——游戏承接上一棒作品留下的残血/空背包存档开场，通关（或放弃夜班）时按组委会 SAVE_STATE v3 协议把状态交给下一棒。全程原生 HTML/CSS/JS 零框架实现，熟练约 3 分钟可通关并到达明确结局。 |
| 目标人群 | 无限世界接力黑客松的评审与玩家；喜欢短时长叙事解谜、深夜便利店氛围、"接力/roguelike 存档继承"玩法的玩家。 |
| 解决什么问题 | 解决接力链条中"存档怎么接、怎么交"的问题：在不允许 localStorage/弹窗/联网的沙盒环境里，安全读取上游作品存档（HP、道具、exit_hook 旁白），通关后仅交档一次（成功 `IW_COMPLETE` / 失败 `IW_FAIL` 生成遗物与墓碑），让每一棒作品都能无缝续写同一个世界。 |
